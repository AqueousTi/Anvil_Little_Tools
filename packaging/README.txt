Little Tools 便携安装包
======================

适用系统：64 位 Windows 10 / Windows 11
需要权限：普通用户即可，不需要管理员权限

安装
----
解压后双击 Start.cmd 即可使用整套工具，无需先安装。
托盘菜单可以打开翻译、问答、截图翻译，或切换余量监控、每日待办和股票观察。
直接打开包内的 AI 助手也会自动启动同一套工具，不会产生第二个托盘。

1. 完整解压 ZIP，不能直接在压缩包预览窗口中运行。
2. 双击 Install.cmd。
3. 程序会安装到当前用户的：
   %LOCALAPPDATA%\LittleTools\App
4. 开机启动使用超轻量入口，正式界面会在登录约 30 秒后出现。

账号配置
--------
双击 Configure.cmd，按提示填写需要使用的服务：
- GLM 或 DeepSeek API Key：用于问答。
- DeepSeek API Key：用于余额和日、周、月用量趋势。
- GLM API Key：用于账户余额、累计消费估算和 Coding Plan 余量。

所有输入均保存在公司电脑的当前 Windows 用户中，安装包里不含原电脑的密钥、待办或使用记录。

文本与截图翻译使用百度翻译开放平台。在翻译窗口左下角语言菜单中打开“翻译设置…”，
填写 APPID 和密钥。旧版百度翻译配置会自动读取；图片翻译服务需单独开通。

每日待办
--------
展开待办面板后点击「周期性任务」，可以建立每天、每周指定星期或每月指定日期自动生成的事项。
自动事项在同一天不会重复；手动删除当天生成的事项后，当天不会再次出现。
当前事项右侧可设置 0–100 分钟的专注倒计时；到时会播放系统提示音，并通过 Little Tools
托盘通知显示结束的事项名称。
展开待办后，左侧堆叠图标可将主界面切换为全局堆积事项；支持暂存当前页面事项、
单项或批量移入今日，以及带撤销的批量删除。

股票观察
--------
输入沪深六位代码可临时查询，也可加入长期监控。ETF 显示 IOPV、参考溢价和 K 线；
510300 与 513500 还会显示跟踪指数的 PE 历史分位。参考溢价低于 2% 时可提醒。
按 Ctrl + Alt + Q 可显示或隐藏股票窗口。跨境 ETF 的 IOPV 与估值存在时差，仅供参考。

Codex 余量
----------
公司电脑安装并登录 Codex 桌面版后，Little Tools 才会读取其余量。
未安装 Codex 时，待办、AI 助手、DeepSeek 和 GLM 功能仍可正常使用，也不会自动安装或启动 Codex。

卸载
----
双击 Uninstall.cmd。卸载默认保留待办、账号配置和历史数据。

提示
----
- 本程序未购买代码签名证书。Windows 首次运行若显示安全提醒，请确认文件来自你自己的 ZIP 后再选择运行。
- 部分公司电脑会被组织策略禁止计划任务；安装器会自动回退到兼容的低占用延迟启动方式。
