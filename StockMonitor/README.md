# Stock Monitor

黑色毛玻璃风格的沪深股票与 ETF 查询、监控窗口。

- 输入六位沪深代码可临时查询，查询结果可加入或移出长期监控。
- ETF 与 LOF 显示现价、可用的 IOPV 和参考溢价；普通股票显示现价和动态 PE。
- K 线支持分时、日 K、周 K、月 K，以及 1 月、1 年、3 年、5 年跨度。
- 510300 使用中证指数官方历史 PE；513500 使用公开的标普 500 月度 PE 历史，并显示数据来源与日期。
- 监控 ETF 的参考溢价从阈值上方跌至 2% 以下时提醒一次，重新升至阈值以上后才会再次触发。
- 溢价低于 2% 时使用白色字芯与渐变彩色描边；达到 2% 后使用灰色普通字体。
- 实时股价与涨跌幅遵循沪深习惯：上涨红色、下跌绿色、平盘白色。
- `Ctrl + Alt + Q` 可在任何程序中显示或隐藏股票窗口。
- 主窗口固定为与 Token 余量监控一致的 `316 × 92` 半透明小框；单击展开明细，再次单击或点击外部自动收回，无额外展开按钮。
- 支持后台监控和窗口置顶。

设置保存在 `%LOCALAPPDATA%\LittleTools\StockMonitor\settings.json`，不会写入程序目录或便携包。

溢价和估值仅供参考。跨境 ETF 的 IOPV、汇率与境内外交易时段不同，不能作为交易承诺。
