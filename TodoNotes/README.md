# 每日待办

Little Tools 的极简本地每日待办模块。

- 每个自然日使用独立待办列表，可查看和编辑任意日期
- 只有真实的今天可以处理真实昨天的未完成事项，可逐项选择加入今日待办、堆积或忽略
- 拖动排序决定优先级，完成事项自动移到底部
- 支持每天、每周指定星期、每月指定日期自动生成的周期性任务
- 完成事项会记住原优先级，取消完成后返回原位置
- 缩小时展示今天最高优先级事项和完成进度
- 当前事项和展开后的任务行支持 0–100 分钟专注倒计时，带 5 分钟吸附和逐分钟刻度音
- 展开界面左侧提供全局堆积事项切换按钮，可拖入暂存，并在主界面中单项或批量移入今日、批量删除撤销
- 黑色半透明圆角纸牌堆，展开时使用交错动画
- 数据保存到 `%LOCALAPPDATA%\LittleTools\DailyTodo`，并保留备份

运行 `build.ps1` 生成 `bin\TodoNotes.exe`。
